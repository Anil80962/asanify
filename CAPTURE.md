# (Moved)

This is now a multi-employee system. The capture step is part of onboarding:

- **Employees:** follow [`ONBOARDING.md`](./ONBOARDING.md) — run `npm run
  capture`, send your two values to the admin.
- **Admin:** see [`README.md`](./README.md) — roster + GitHub secrets + deploy.

The diagnostic scripts that reverse-engineered the API (`parse-har.cjs`,
`inspect-*.cjs`, `extract-secrets.cjs`) are kept for reference only; they're
not part of the running system.
